# Ritual Fasting App (Expo)

This is a minimal, production-ready fasting app built with React Native and Expo.

## Getting Started

1.  **Install dependencies:**
    ```bash
    npm install
    ```

2.  **Run the app:**
    ```bash
    npx expo start
    ```

This will start the Metro bundler. You can then run the app on an iOS simulator, Android emulator, or on your physical device using the Expo Go app.

## Environment Variables

The AI Mentor feature requires a Google Gemini API key. Create a `.env` file in the root of the project and add your key:

```
EXPO_PUBLIC_API_KEY="YOUR_GEMINI_API_KEY"
